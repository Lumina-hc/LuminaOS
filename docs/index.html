LuminaOS

A hobby operating system for x86-64 built from scratch — bootloader, kernel, desktop, and ELF64 apps.

View on GitHub Build Now

Features

Custom Bootloader

Boots a 1.44 MB floppy straight into 64-bit long mode.

Memory Management

Physical memory manager with paging support.

Desktop Environment

VBE graphics (800x600) with a windowed desktop, icons, and mouse support.

FAT16 Filesystem

Full FAT16 support on IDE disk images.

ELF64 Applications

Run user-space apps compiled to ELF64 in ring 3, loaded by the kernel.

Built-in Apps

Notepad, Files, About, System — ready to use.

Build

  1. Install dependencies: NASM x86_64-elf-gcc QEMU
  2. Clone the repository: git clone https://github.com/Lumina-hc/LuminaOS.git
  3. Enter the directory: cd LuminaOS
  4. Build: .\build.ps1
  5. Run in QEMU: .\run.ps1
